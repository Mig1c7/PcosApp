# PcosApp — Steady PCOS Guide

A calm, single-page guide to adrenal-pattern PCOS.

- **Understand** — each topic in plain words with the clinical version beside it, plus an evidence table of what works.
- **My labs** — upload a PDF/text lab report, paste it, or type values in; each result is explained against your lab's range or a general one.
- **Daily routine** — a day template that highlights what matters for the levels that are off.
- **Goals** — one-time groundwork, daily steps and a weekly rhythm.

## Run it

Open `index.html` in a browser. There is no build step and no server. Lab values and goals are stored only in the browser's local storage; nothing is uploaded.

To host it, enable GitHub Pages for this repository (Settings → Pages → deploy from branch).

## Notes

Content is based on the 2023 International Evidence-based Guideline for PCOS and the sources listed in the app. It is educational and does not replace medical advice.
